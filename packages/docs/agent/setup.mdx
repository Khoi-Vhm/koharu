Koharu Agent is a Codex client inside the editor. It uses ChatGPT device-code sign-in; you do not enter an OpenAI API key for the Agent.

<Steps>
  <Step title='Open the Agent panel'>Open a project and select **Agent** on the right.</Step>
  <Step title='Authorize the device'>
    Choose **Sign in with Codex**. Koharu opens the authorization page in your browser; enter the
    code shown in the panel and approve the sign-in for your account. The code expires after 15
    minutes.
  </Step>
  <Step title='Choose a model'>
    Return to Koharu and wait for the account and model list. Select a Codex model and reasoning
    level at the top of the Agent panel; **Automatic** uses the first available model. More
    reasoning can help with ambiguous edits but takes longer.
  </Step>
</Steps>

Only one sign-in attempt can run at a time. Cancel it before starting another.

## What context is shared

The Agent starts with the open project's semantic state. It renders and attaches a page image only when it invokes visual page inspection; it does not automatically attach every page.

<Note>
  Codex translation shares the Agent sign-in. Other translation-provider credentials are separate.
  ChatGPT sign-in does not configure the pipeline's OpenAI provider, and an OpenAI API key does not
  sign in the Agent.
</Note>

## Translate with Codex

After signing in, choose a **Codex** model in the processing selector or **Settings → Translation**.
Translate and full processing use this selection independently of the Agent panel's model.
The translator sends OCR segments, the target language, translation instructions, and the
source page image when **Vision** is enabled and supported. It does not send Agent chat history
or give the model project-editing tools. Signing out also removes access to Codex translation
for subsequent requests.

## Sign out

**Sign out** cancels Agent work, clears the current Agent session, and removes the Codex account authorization used by Koharu. Opening or closing a project also clears the conversation. Agent configuration is saved separately from translator settings.
